# ROADGUARD · RoadResQ

واجهة موقع نظام كشف الحوادث بالذكاء الاصطناعي (مشروع تخرج، جامعة آل البيت).
موقع ثابت (HTML / CSS / JavaScript) بدون أي build، بيشتغل على Vercel أو Netlify أو GitHub Pages مباشرة.

## الملفات

```
index.html            الصفحة (البداية + غرفة العمليات + بلاغ المواطن)
css/style.css         كل التصميم
js/app.js             كل التفاعل: اللغة، الصفحات، الخريطة، البلاغ
js/jordan-data.js     خريطة الأردن: الحدود والمحافظات والطرق والمدن (Natural Earth)
vendor/leaflet/       مكتبة الخريطة Leaflet 1.9.4
assets/img/           الصور
assets/video/         فيديو الكاميرا التجريبي
```

## التعديل
- النصوص بالعربي والإنجليزي: داخل `js/app.js` بالكائن `T` (المفتاح `ar` والمفتاح `en`).
- الألوان: أول سطور `css/style.css` (`--red` و `--bg` ...).
- الصور: بدّل الملفات بـ `assets/img/` بنفس الأسماء.

## ملاحظات
- كل البيانات (الحوادث، الزحمة، تسجيل الدخول) **تجريبية**، وما في سيرفر حقيقي لسا.
- الخطوة الجاية: ربط زر "تحليل فيديو" بالـ Flask API اللي بيشغّل `run_on_video.py`.
- صور البداية من Pexels و Unsplash (رخصة مجانية).
